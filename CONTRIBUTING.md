# Contributing

Thank you for helping keep this list current.

## Adding a paper
Open a pull request that adds one line to the matching section of `README.md`:

```
- **Paper Title** — Venue Year [[arXiv](https://arxiv.org/abs/<id>)] [[code](https://github.com/<owner>/<repo>)]
```

Please include the paper in the section that matches the survey's taxonomy (representation family, architecture, or dataset). If unsure, open an issue instead.

## Adding a dataset
Add a row to both `datasets.csv` and the dataset table in `README.md`, using the same columns: Setting, Dataset, Year, Modalities, Scale, Region, Primary tasks. Scale figures should follow the dataset's original paper.

## Adding a result
Add a row to the Benchmark Snapshot table with a link to the source paper or official leaderboard. For USR-5 results, report all five per-test scores and the aggregate.

## Corrections
If a description of your work is inaccurate, please open an issue or a pull request; corrections are prioritized.
